# NekoDesk

Десктопное приложение (Windows, PySide6) для организации локальной библиотеки
аниме: сканирование папок с релизами, разбор имён файлов (`anitopy`),
переименование по шаблону, синхронизация с личными списками **AniList** и
**Shikimori**, а также (опционально) переименование файлов прямо внутри
торрента через **qBittorrent Web API**, без разрыва сидирования.

> Пилилось для себя, багов может быть много.
> Часть кода создано ИИ.

## Возможности

- Локальная библиотека тайтлов (SQLite) с постерами.
- Импорт списков из AniList и Shikimori (Watching/Planning/Completed/...).
- Автоматический разбор релизов в папке: фансаб-группы, разрешение,
  источник (BDRip/WEB-DL/...), номера эпизодов.
- Массовое переименование файлов/папок по шаблону
  (`{title}`, `{episode}`, `{resolution}`, `{fansub}` и т.д.).
- Откат переименования (Restore) по скрытому снимку исходных имён.
- Переименование файлов торрента через qBittorrent API (без потери
  сидирования и без ре-хэша).

## Требования

- **Windows** (используется `winreg` для определения светлой/тёмной темы).
- Для сборки/запуска из исходников — Python 3.11+.
- Опционально: qBittorrent с включённым Web UI, если нужна интеграция
  с торрентами.

## Установка

### Готовый .exe

Скачай последний релиз из раздела [Releases](../../releases) и запусти
`NekoDesk.exe`. При первом запуске рядом с файлом появится папка `data/` —
там хранятся локальная библиотека и настройки. Ничего вручную создавать
не нужно.

### Из исходников

```bash
git clone https://github.com/RealMihp/nekodesk
cd nekodesk
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

## Настройка

### AniList / Shikimori

В настройках приложения — авторизация через браузер (OAuth). Токен
сохраняется в системном хранилище учётных данных Windows через `keyring`,
в репозиторий и файлы приложения он не попадает.

### qBittorrent (опционально)

В настройках включи интеграцию с qBittorrent и укажи:

- адрес и порт Web UI;
- логин;
- пароль (сохраняется через `keyring`, не в открытом виде).

Без этого приложение работает как обычный локальный переименователь файлов
(`os.rename`), без завязки на торрент-клиент.

## Известные ограничения

- Только Windows.
- Восстановление имён (Restore) для торрент-релизов надёжно работает только
  если qBittorrent доступен и торрент найден по пути — иначе откат идёт
  обычным переименованием на диске, и состояние торрента в клиенте может
  разойтись с диском.
- Разбор имён файлов зависит от `anitopy` и качества самого имени релиза —
  на нестандартных/кривых именах может ошибаться.

## Отказ от ответственности

Проект не аффилирован с AniList, Shikimori или qBittorrent и использует
только их публичные API. Приложение переименовывает и перемещает файлы на
диске — перед использованием на важных данных сделай бэкап. Автор не несёт
ответственности за потерю данных, сломанные торренты и т.п. — см. LICENSE.
